# Apurba Rath: Portfolio

Personal portfolio and marketing highlights for **Apurba Rath** - Content Marketing Leader & Founding Marketing Manager.

Built with [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com), [React](https://react.dev), and [shadcn/ui](https://ui.shadcn.com). Deployed on [Vercel](https://vercel.com).

## Highlights

- **Hero & Identity**: Professional summary and links to LinkedIn, Email, and Portfolio Deck
- **Work Experience**: Leadership roles at Uniblox, Phenom People, Saras Analytics, Green Turtle Gaming, and K12 Techno Services
- **Featured Projects**: B2B product marketing launches, content operating systems, and campaign case studies
- **Skills & Tooling**: CMS platforms (HubSpot, Webflow, WordPress, Contentful), SEO suites (Ahrefs, SEMrush, Screaming Frog), and analytics
- **Insights**: Practical guides on building B2B content engines and multi-site SEO governance

## Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```

## Deployment

Deployed statically to Vercel. Pushes to the `main` branch trigger automatic continuous deployments.
